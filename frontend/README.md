# SafeShift Frontend

React + Vite + TypeScript + Leaflet dashboard for SIH 26191, Chamoli Uttarakhand.

## Run

```bash
npm install
copy .env.example .env
npm run dev
```

Backend expected at `http://localhost:5000/api` by default.

If the API is unavailable, the UI automatically uses clearly labelled demo data so frontend testing can continue.
